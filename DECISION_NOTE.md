# Parallax - Decision Note

Parallax is a bounded three-role research system built around evidence transparency. The Planner converts a user query into exactly four focused, non-overlapping tasks. Stateless Researchers execute those tasks in parallel, search broadly, deduplicate URLs, rank sources, fetch a bounded shortlist, and immediately compress each useful page into a validated evidence observation. A single controlled writer attaches observations to claims in an in-memory Evidence Ledger. The combined Critic/Synthesizer checks coverage and disagreement, may issue at most two depth-one follow-ups, performs one final check, and produces a concise cited report. JSON schemas define every role handoff; JSONL events, the ledger dump, and the final report make a run auditable.

I rejected an agent swarm, deep recursive task trees, a general orchestration framework, embeddings, a vector database, and persistent storage for V1. Those choices would increase coordination risk, latency, and debugging cost without improving the central evaluation target. I also avoided semantic claim merging because an incorrect merge can inflate source support and hide real disagreement. Exact conservative grouping is safer for an inspectable first version, while the data model leaves room for controlled claim normalization later.

Cost and speed are controlled in code rather than prompt convention. Research tasks, searches, pages, concurrent fetches, model calls, follow-ups, recursion depth, and wall-clock time all have hard ceilings. Breadth comes from diverse parallel searches and screening hundreds of results; expensive page extraction is reserved for a ranked shortlist. Tavily provides search and focused extraction, while Claude Sonnet 4.6 through Amazon Bedrock handles structured planning, evidence extraction, critique, and synthesis. Sonnet was selected as the practical balance of structured-output quality, latency, account availability, and cost. Pages are compressed before synthesis, so raw documents never accumulate in the final context.

The deliberate V1 cuts are multi-turn memory, authentication, persistent sessions, semantic clustering, independence tracing, and further self-reflection loops. The result is smaller, but it runs end to end, fails closed on budget and depth violations, preserves contradictory evidence, and remains straightforward to inspect and extend.
